# Lingue del gioco

Questo port usa il disco europeo `BCES00511`. La lingua si sceglie in [avvia.bat](avvia.bat).

## Come cambiare lingua

1. Apri `avvia.bat` con il Blocco note.
2. Cambia il valore in questa riga, in alto:

   ```bat
   set "LINGUA=it"
   ```

3. Salva e avvia il gioco con un doppio clic su `avvia.bat`.

## Lingue disponibili

| Codice | Lingua | Stato |
| --- | --- | --- |
| `it` | Italiano | Provata |
| `en` | Inglese | Da provare |
| `fr` | Francese | Da provare |
| `es` | Spagnolo | Da provare |
| `de` | Tedesco | Da provare |
| `nl` | Olandese | Da provare |

Un codice non in tabella fa partire il gioco in inglese.

## Altre lingue sul disco

I filmati hanno pacchetti anche per queste lingue, ma per ora non si possono selezionare:

| Suffisso | Lingua |
| --- | --- |
| `gb` | Inglese britannico |
| `dk` | Danese |
| `se` | Svedese |
| `no` | Norvegese |
| `fi` | Finlandese |
| `pt` | Portoghese |
| `jp` | Giapponese |
| `kr` | Coreano |
| `cn` | Cinese |

La presenza dei pacchetti non garantisce che testi e doppiaggio siano completi. I dialoghi dei livelli
sono stati visti solo per `us gb fr it de es nl`.
